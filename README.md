# Пульт Аниме-ТВ

Страница-пульт для программы «Аниме-ТВ» (ПК и приставка Android TV / Freebox).

Без QR-кода с экрана эта страница ни к чему не подключится: у каждого экрана свой секретный ключ,
он передаётся только в QR (в части адреса после `#`, на сервер не уходит). Команды и состояние
идут через публичные MQTT-брокеры и зашифрованы AES-256-GCM.
